# Capitals

Capitals is an offline atlas and quiz for the capitals of every country and every U.S. state, territory and the federal district.

## Files and badge runtime

- `__init__.py`: badge entry point, screens and input.
- `quiz.py`: quiz rules (orders, passes, rounds, choices), free of badge APIs.
- `explore.py`: Explore navigation shared by the list and the map.
- `progress.py`: saved settings, scores and quiz progress, with migration.
- `layout.py`: text wrapping and paging helpers.
- `catalog.py`, `atlas.py`, `assets/maps/*.png`, `data/`, `DATA-SOURCES.md` and
  `MAP-ATTRIBUTION.md`: the geography catalog, the map pages and their sources,
  generated by `scripts/build-capitals-catalog.py` and
  `scripts/build-capitals-maps.py`.

Launch it through the badge menu, which provides the display, fonts, colors,
buttons and `run` globals, plus `badgeware.State`. It is not a standalone
desktop Python application. To install, copy this entire `capitals` folder to
`apps/capitals/` on the badge's BADGER storage volume (double-tap RESET or open
**Mass Storage** to show it), then eject BADGER. The entry point uses the
internal path `/system/apps/capitals`, so keep the folder name. No Wi-Fi,
extra hardware or `secrets.py` values are needed.

## Coverage

- **World:** the 193 UN member states and the 2 UN observer states, 195 in all,
  grouped by Africa, Asia, Europe, North America, South America and Oceania.
  Antarctica has a map page with no countries and no quiz.
- **United States:** the 50 states, the five inhabited territories (Puerto Rico,
  American Samoa, Guam, U.S. Virgin Islands, Northern Mariana Islands) labelled
  as territories, and the District of Columbia labelled as a federal district;
  56 places, never counted as states.
- Countries with more than one capital, a separate seat of government or no
  official capital are asked with a precise question ("Constitutional capital of
  Bolivia?"), and their note is shown after the answer. Coverage date, sources
  and exceptions are in `DATA-SOURCES.md`.

## Usage

The menu offers **World**, **United States** and **Settings**. Each scope screen
offers **Explore**, **Quiz**, a region (World) or filter (United States:
All 56, States, Territories, District, or a census region) and the question
order, **Random** or **Alphabetical**, kept separately for each scope.

**Explore** opens an alphabetical list: UP/DOWN move, LEFT/RIGHT change page,
SELECT shows the place on a map. On the map, LEFT/RIGHT step through the places
on that page (the marker and caption follow), UP/DOWN change map page (detail,
continent, world), SELECT opens the detail card, and BACK returns to the list
at the same place. The caption names the capital's actual role when it is not a
plain capital ("Government district: Yaren", "Federal city: Bern"). The detail
card shows the name, capital, kind, region, subregion and any note; LEFT/RIGHT
move to the next place.

**Quiz** shows the scope, region, order and pass progress, then asks rounds of
five questions with four choices: UP/DOWN pick, SELECT checks. Feedback uses
words, a mark and colour, shows the right answer and the full note (a note too
long for the screen gets its own page first); SELECT continues. Results list
every missed place with your answer. A pass continues through the
whole pool across rounds: random order never repeats a place until every place
has been asked, alphabetical order walks the pool by name. When the pass is
complete, SELECT reshuffles (random) or starts again from A (alphabetical).
BACK or HOME mid-round keeps the answered questions and returns the rest to the
pass. Changing the region, filter or order starts a new pass.

**Settings** holds both scopes' order and region/filter and **Reset quiz
passes**, which forgets both passes after confirmation but keeps your best
round and rounds played. HOME returns to the badge menu from anywhere.

## Saved state

`/state/capitals.json` keeps `best` and `played` from the first version, the
settings per scope and each scope's pass (question order by id, position and
pass totals). Progress is dropped and restarted, never the scores, when the
data release changes or the saved order no longer matches the pool.

## Host checks

From the repository root, use the project's Python environment:

```bash
python -m unittest discover -s tests -p "test_capitals*.py"
```

`test_capitals.py` covers the quiz rules and, with the catalog present, the
pool sizes, ids, kinds, regions, sort order and a full cycle of every pool and
region in both orders; `test_capitals_explore.py` covers Explore navigation and
saved-state migration; `test_capitals_layout.py` covers wrapping and paging;
`test_capitals_catalog.py` and `test_capitals_atlas.py` cover the data and map
projection. None of them open the badge UI. Physical badge rendering, button
handling, memory and persistence need a separate device check.
