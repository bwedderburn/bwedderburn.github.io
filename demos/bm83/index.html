Keyboard controls and credits

With the demo focused: Space plays or pauses; left/right arrows change track; up/down arrows adjust volume; M mutes; S opens settings; Escape returns home. Sliders and other form controls retain their normal keyboard behavior.

The badge keeps its existing Mona artwork, GitHub logo and controls. The five album covers are original generated artwork. The public 3D view loads the badge model from the official simulator’s host; it requires an internet connection. The renderer uses Three.js under its MIT license and retains the HYB26 software notice. See sources and credits. Using this demo makes no AI requests.
