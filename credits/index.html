The GitHub Universe badge

The badge behind the app.

The BM83 demo depicts the GitHub Universe 2026 badge, made by Pimoroni in Sheffield, UK. It retains the badge’s existing Mona artwork, GitHub logo, five physical buttons and eight touch controls while showing my independent remote app.

The public demo loads the model from the official badge simulator. Its original source is Lee Reilly’s H4X0R3D showcase; the simulator’s model provenance record describes the source and subsequent case modifications. The portfolio repository does not contain another copy of that model or claim it is public domain.

The renderer retains the HYB26 MIT software notice and the Three.js MIT notice. The badge firmware is shared by Pimoroni and GitHub under its MIT license.

The existing marks identify the hardware and event being discussed. They are not this portfolio’s logo, and this independent project does not imply sponsorship or endorsement.

The orbital workshop sessions

Five covers for a fictional catalog.

Universe After Hours, Control Loop, Midnight on the Bus, Setpoint After Dark, and Phase Margin each have original AI-generated artwork created for this portfolio. The images explore space, instrumentation, electronics, and feedback control.

The tracks demonstrate metadata, artwork and controls. Playback is simulated, and no audio recordings are included. Images are bundled with the site; visitors’ interactions do not make AI requests.

World Capitals

Sourced geography, bundled maps.

The Capitals browser demo runs the existing badge app in MicroPython WebAssembly. The app, its catalog and its map pages are bundled together, with runtime notes and retained dependency notices.

The catalog credits GeoNames under CC BY 4.0, with documented corrections and named capital roles. The maps use Natural Earth public-domain geography. Read the app's data sources and map attribution for the snapshot, licenses and build conventions.
